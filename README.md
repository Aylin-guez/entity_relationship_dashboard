# Entity Relationship Mapping Dashboard

Investigative-style dashboard built with Python and Power BI to reconstruct relationships between entities, identify risk indicators, and visualize transactional activity.

---

## Project Overview

This project simulates a financial intelligence workflow where transactional records are transformed into actionable insights.

Using Python, synthetic datasets are generated and enriched before being analyzed in Power BI through multiple interactive dashboards.

The objective is to demonstrate:

- Relationship reconstruction
- Risk monitoring
- Transaction analysis
- Timeline reconstruction
- Interactive investigation workflows

---

## Dashboard Pages

### Transaction Intelligence Overview

High-level view of:

- Total transactions
- Total volume
- Total entities
- Flagged transactions
- Transaction type distribution
- Top active entities

### Entity Relationship Mapping

Interactive relationship visualization showing connections between entities and transaction flows.

### Risk Monitoring & Flagged Activity

Focused view of:

- High-risk entities
- Flagged transactions
- Risk level analysis

### Event Timeline Reconstruction

Chronological reconstruction of significant events across the dataset.
